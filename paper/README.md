# MarketRank paper

Build with `./build.sh` (pdflatex, bibtex, pdflatex, pdflatex); the output is `marketrank.pdf`, which is not committed.
In Texmaker, open `marketrank.tex`, set Quick Build to "PdfLaTeX + Bib(la)tex + PdfLaTeX (x2) + View PDF", and press F1.
Sources: `marketrank.tex`, `marketrank.bib`, the Elsevier template files `elsarticle.cls` and `elsarticle-num.bst`, and figures in `figs/`.
